# SmartHire – Job Portal & Placement Management System

SmartHire is a MERN Stack based Job Portal and Placement Management System designed to connect students, recruiters, and administrators on a single platform.

## 🚀 Features

### 👨‍🎓 Student
- Student Registration and Login
- Browse Available Jobs
- Search and Location Filter
- Apply for Jobs
- View My Applications
- Track Application Status

### 🏢 Recruiter
- Recruiter Registration and Login
- Recruiter Dashboard
- Post New Jobs
- View Applicants
- Shortlist or Reject Applications

### 👨‍💼 Admin
- Admin Login
- View Students
- View Recruiters
- View Jobs
- Manage the Placement System

## 🛠️ Technologies Used

- React.js
- Node.js
- Express.js
- MongoDB
- Mongoose
- JavaScript
- HTML
- CSS
- Git & GitHub
